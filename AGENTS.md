# Архитектура проекта

Это React-приложение с MapLibre. Код организован по назначению и доменам, а не по типам файлов.

```text
src/
├── app/                     # Точка сборки приложения и глобальные стили
├── widgets/map/             # Жизненный цикл экземпляра MapLibre, восстановление камеры и контроллер композиции GeoJSON-слоёв
├── entities/                # Доменные данные карты: здания, улицы, базовая карта
│   ├── <domain>/map/        # Источник GeoJSON/тайлов и спецификации его слоёв
│   └── map-object/map/      # Реестр подключаемых GeoJSON-доменов и общий контракт descriptor
├── features/                # Самостоятельные пользовательские возможности
│   ├── map-language/        # Переключение языка интерфейса
│   │   └── ui/              # React-компонент и локальные стили фичи
│   ├── map-search/          # Fuse-поиск по локализованным items, подсветка и фокусировка результатов на карте
│   │   ├── model/           # Индекс и вычисление геометрических границ
│   │   └── ui/              # Поле поиска и список релевантных результатов
│   ├── object-inspector/    # Не-модальная выезжающая панель результатов поиска и деталей GeoJSON-объекта
│   │   ├── model/           # Стабильная identity объекта и локализация его полей из raw GeoJSON
│   │   └── ui/              # Список плиток, карточка объекта и адаптивный размер панели
│   └── <feature>/ui/        # React-компоненты и локальные стили остальных фич
├── infra/nginx/             # Конфигурация раздачи тайлов и GeoJSON с CORS
└── shared/                  # Переиспользуемая конфигурация и утилиты без доменной логики
    ├── config/map.ts        # Базовые подложки и типизированные MapLibre-темы GeoJSON-оверлеев
    └── lib/
        ├── geojson/         # Загрузка raw GeoJSON, нормализация fid и локализация label
        └── map/             # Слияние доменной спецификации слоя с MapLibre-темой
translates/                  # Локализованные данные; UI-строки находятся в ключе interface
public/                      # Статические файлы Vite, раздаваемые same-origin
├── geojsons/                # Исходные GeoJSON зданий, улиц и beer-точек
└── assets/                  # Общие изображения и иконки
```

## Правила

- Экземпляр MapLibre создаётся только в `widgets/map/ui/MapCanvas.tsx`. React-компоненты получают его через props или будущий контекст, но не создают вторую карту.
- Источник, идентификаторы слоёв и их MapLibre-стили хранятся рядом с соответствующей доменной областью в `entities/<domain>/map`.
- Домены `building`, `street` и `beer` определяют собственные источники и слои; `widgets/map/model/MapObjectLayersController` только координирует их загрузку, текущий язык и тему подложки.
- Каждый GeoJSON-домен публикует `map/domain.ts` descriptor с источником, регистрацией, темой и search-подсветкой. `entities/map-object/map/domains.ts` — единственный реестр этих descriptor'ов, который используют и контроллер карты, и поиск; при добавлении домена не создавайте второй список источников.
- Пользовательская логика живёт в `features/<feature>`: выбор растровой подложки с превью — `features/map-basemap-switcher`, поиск — `features/map-search`, переключатель языка — `features/map-language`, выбор слоёв — `features/map-layers`, карточка объекта — `features/object-inspector`. Инспектор получает только raw-ссылки из реестра доменов; при его открытии App измеряет ширину панели и применяет её к MapLibre padding.
- Поиск строит Fuse-индекс только по `items` выбранной локали (`title`, `description`, `aliases`). Подсветка принадлежит `features/map-search`: она передаёт идентичность `sourceId + Feature.id` доменным search-слоям, которые рисуют красную обводку, а для полигонов — также полупрозрачную заливку поверх тех же GeoJSON-источников. Не создавайте отдельную копию GeoJSON для результатов.
- Поиск запускается единым действием через Enter, кнопку-лупу или выбор подсказки. Для подсказки передаётся её точный `items.id`, даже если несколько объектов имеют одинаковый заголовок.
- Границы и идентичность результатов поиска берутся контроллером из raw GeoJSON доменов, а не через `querySourceFeatures()`: последний зависит от загруженных в текущем viewport тайлов и масштаба.
- Общие настройки карты находятся в `shared/config/map.ts`; не дублируйте URL и настройки слоёв в UI-компонентах. Тема задаёт типизированные патчи конкретных слоёв (`filter`, `layout`, `paint`, zoom); выражения остаются нативными выражениями MapLibre. Идентификатор, тип, источник и базовый геометрический фильтр принадлежат доменному модулю слоя.
- Конфигурация `i18next` находится в `shared/config/i18n.ts`; список языков собирается из файлов `translates/<locale>.json`, а выбор пользователя сохраняется в `localStorage`. Если ключ отсутствует в выбранной локали, используется значение из английского файла. Все видимые строки и метаданные языка (`interface.language.name`, `interface.language.flag`) добавляйте под ключом `interface`.
- Общие визуальные ассеты размещайте в `public/assets/images` и `public/assets/icons`; подключайте их по same-origin URL. Ассет, принадлежащий только одной фиче, храните рядом с ней.
- Любое добавление, удаление или существенное изменение фичи обязательно сопровождается обновлением этого `AGENTS.md`: добавьте её место в дереве и кратко опишите ответственность.

## MapLibre и React

MapLibre остаётся императивным адаптером визуализации, а React хранит состояние интерфейса: активный слой, строку поиска, выбранный объект, язык и открытую карточку. Изменения React state применяются к карте через `useEffect` и методы MapLibre (`setFilter`, `setLayoutProperty`, `setPaintProperty`, `fitBounds`, `setFeatureState`). Не храните GeoJSON-копии в нескольких местах: доменный модуль источника — единственный источник его конфигурации. Raw GeoJSON не изменяется: перед передачей в MapLibre создаётся клиентская копия с `Feature.id = fid` и локализованным `properties.label`. Для `label` используется выбранная локаль, затем английская, а при отсутствии обоих названий подпись не отображается.
