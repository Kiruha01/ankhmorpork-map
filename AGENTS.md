# Архитектура проекта

Это React-приложение с MapLibre. Код организован по назначению и доменам, а не по типам файлов.

```text
src/
├── app/                     # Точка сборки приложения, глобальные стили и model/mapPreferences.ts для сохранения переключателей
├── widgets/map-controls/    # Правая группа меню языка, маркеров и слоёв; одно открытое меню, Escape и возврат фокуса
├── widgets/map/             # Жизненный цикл экземпляра MapLibre, восстановление камеры и контроллер композиции GeoJSON-слоёв
├── entities/                # Доменные данные карты: здания, улицы, растровая и векторная базовая карта
│   ├── <domain>/map/        # Источник GeoJSON/тайлов и спецификации его слоёв (building, street, beer, park, square)
│   └── map-object/map/      # Реестр подключаемых GeoJSON-доменов и общий контракт descriptor
├── features/                # Самостоятельные пользовательские возможности
│   ├── map-markers/         # JSON-совместимый каталог категорий с двумя моками, чекбоксы и DOM-маркеры MapLibre
│   ├── map-layers/          # Динамические настройки подложки и feature flags: GeoJSON, zoom и элементы управления картой
│   ├── map-language/        # Переключение языка интерфейса
│   │   └── ui/              # React-компонент и локальные стили фичи
│   ├── map-search/          # Fuse-поиск по локализованным items, подсветка, фокусировка и закреплённая сверху строка с подсказками
│   │   ├── model/           # Индекс и вычисление геометрических границ
│   │   └── ui/              # Поле поиска и список релевантных результатов
│   ├── object-inspector/    # Не-модальная панель результатов и деталей GeoJSON-объекта; на мобильных — нижняя панель с тремя положениями
│   │   ├── model/           # Стабильная identity объекта и локализация его полей из raw GeoJSON
│   │   └── ui/              # Список плиток, карточка объекта и адаптивный размер панели
│   └── <feature>/ui/        # React-компоненты и локальные стили остальных фич
├── infra/nginx/             # Конфигурация раздачи тайлов и GeoJSON с CORS
└── shared/                  # Переиспользуемая конфигурация и утилиты без доменной логики
    ├── config/map.ts        # Растровые и векторная подложки, типизированные MapLibre-темы GeoJSON-оверлеев
    └── lib/
        ├── geojson/         # Загрузка raw GeoJSON, нормализация fid и локализация label
        └── map/             # Слияние доменной спецификации с темой и загрузка изображений, включая SVG
translates/                  # Локализованные данные; UI-строки находятся в ключе interface
public/                      # Статические файлы Vite, раздаваемые same-origin
├── geojsons/                # Исходные GeoJSON доменов и landscape/style.json с данными векторной подложки
└── assets/                  # Общие изображения, иконки и локальные PBF-глифы Open Sans
.github/workflows/           # Сборка и фиксация закрытия PR без прав записи, проверка artifacts и публикация/удаление превью в gh-pages
```

## Правила

- Экземпляр MapLibre создаётся только в `widgets/map/ui/MapCanvas.tsx`. React-компоненты получают его через props или будущий контекст, но не создают вторую карту.
- Источник, идентификаторы слоёв и их MapLibre-стили хранятся рядом с соответствующей доменной областью в `entities/<domain>/map`.
- Домены `building`, `street`, `beer`, `park` и `square` определяют собственные источники и слои; `widgets/map/model/MapObjectLayersController` только координирует их загрузку, текущий язык и тему подложки. У парков и площадей обычное отображение ограничено подписями; полигоны появляются только как подсветка поискового результата.
- Каждый GeoJSON-домен публикует `map/domain.ts` descriptor с источником, регистрацией, темой и search-подсветкой. `entities/map-object/map/domains.ts` — единственный реестр этих descriptor'ов, который используют и контроллер карты, и поиск; при добавлении домена не создавайте второй список источников.
- Пользовательская логика живёт в `features/<feature>`: выбор подложки с превью — `features/map-basemap-switcher`, поиск — `features/map-search`, переключатель языка — `features/map-language`, выбор слоёв — `features/map-layers`, карточка объекта — `features/object-inspector`. `entities/base-map/map` подключает растровые тайлы или слои локального `landscape/style.json` под доменными слоями без замены экземпляра карты. Строка поиска остаётся поверх открытого инспектора. Инспектор получает только raw-ссылки из реестра доменов; при его открытии App измеряет размер и placement панели и применяет их к MapLibre padding. На ширинах до 767px App назначает `app--mobile`: инспектор становится нижней sheet-панелью с положениями «спрятана до ручки», обычным и раскрытым; карта учитывает её текущую высоту.
- Поиск строит Fuse-индекс только по `items` выбранной локали (`title`, `description`, `aliases`). Подсветка принадлежит `features/map-search`: она передаёт идентичность `sourceId + Feature.id` доменным search-слоям, которые рисуют красную обводку, а для полигонов — также полупрозрачную заливку поверх тех же GeoJSON-источников. Не создавайте отдельную копию GeoJSON для результатов.
- Поиск запускается единым действием через Enter, кнопку-лупу или выбор подсказки. Для подсказки передаётся её точный `items.id`, даже если несколько объектов имеют одинаковый заголовок.
- Границы и идентичность результатов поиска берутся контроллером из raw GeoJSON доменов, а не через `querySourceFeatures()`: последний зависит от загруженных в текущем viewport тайлов и масштаба.
- Общие настройки карты находятся в `shared/config/map.ts`, а общий responsive media query — в `shared/config/layout.ts`; не дублируйте URL, breakpoint и настройки слоёв в UI-компонентах. Тема задаёт типизированные патчи конкретных слоёв (`filter`, `layout`, `paint`, zoom); выражения остаются нативными выражениями MapLibre. Идентификатор, тип, источник и базовый геометрический фильтр принадлежат доменному модулю слоя.
- Конфигурация `i18next` находится в `shared/config/i18n.ts`; список языков собирается из файлов `translates/<locale>.json`, а выбор пользователя сохраняется в `localStorage`. Если ключ отсутствует в выбранной локали, используется значение из английского файла. Все видимые строки, заголовок вкладки (`interface.siteTitle`) и метаданные языка (`interface.language.name`, `interface.language.flag`) добавляйте под ключом `interface`.
- Общие визуальные ассеты размещайте в `public/assets/images` и `public/assets/icons`; подключайте их по same-origin URL. Ассет, принадлежащий только одной фиче, храните рядом с ней.
- SVG-иконки интерфейса храните в `public/assets/icons` и подключайте внешними файлами без inline SVG. Иконка слоёв `layers.svg` подключается через CSS mask, чтобы наследовать цвет кнопки, включая открытое состояние меню; поиск использует `search.svg` через `img`.
- Подписи MapLibre используют локальные PBF-глифы `public/assets/glyphs/Open Sans Regular` через URL в `shared/config/map.ts`. При появлении новых символов в подписях добавляйте соответствующий диапазон из 256 кодовых точек Unicode вместе с файлами шрифта; лицензию храните рядом.
- Здания с `build_type` guild, temple, university и citywatch используют одноимённые SVG из `public/assets/icons` через `icon-image`. Общие параметры задаёт `createMapIcon(fileName, size = 32)` в `shared/config/map.ts`: same-origin URL, квадратный размер растеризации и `pixelRatio: 2`. Загрузчик декодирует SVG и применяет размер перед регистрацией в MapLibre.
- Иконки пива прозрачны при zoom ≤16 и плавно появляются от 16 до 16.1 через `icon-opacity` в теме. Слой подписей и иконок зданий показывается с zoom 14 без этого ограничения прозрачности.
- Точки домена `beer` отображаются symbol-слоем `beers-points` с `public/assets/icons/beer.svg` (64×64, `pixelRatio: 2`, `icon-size: 0.8`) вместо обычных кругов. Загрузчик поддерживает опциональный ореол через `images.halo`, сейчас он не задан. Слой остаётся интерактивным; подписи и красная круговая подсветка результатов поиска подключаются отдельно.
- Любое добавление, удаление или существенное изменение фичи обязательно сопровождается обновлением этого `AGENTS.md`: добавьте её место в дереве и кратко опишите ответственность.
- Workflow `deploy-pages.yml` обновляет корень `gh-pages`, сохраняя `pr-preview`. `pr-preview.yml` собирает PR с base URL для номера PR и без прав записи; `publish-pr-preview.yml` проверяет artifact и актуальность PR перед публикацией через `rossjrw/pr-preview-action`. `close-pr-preview.yml` фиксирует закрытие PR без прав записи, а `remove-pr-preview.yml` проверяет его artifact и удаляет превью без `pull_request_target`. Публикация и удаление одного PR выполняются последовательно, без принудительной перезаписи ветки `gh-pages`.

- `BASE_MAP_VARIANTS` задаёт независимые `visibilityOptions` каждой подложки: локализованный ключ, значение по умолчанию и типизированные цели в overlay-теме. UI строит чекбоксы из конфигурации; App хранит значения по подложкам, контроллер применяет их к копии темы. Базовые стили и search-подсветка не меняются. Растровые подписи внутри изображения тайла не отключаются.
- Раздел чекбоксов «Отображение» в `MapLayers` называется **feature flags**: глобальные `showAttributes`, `showZoom` и `showNavigation` хранятся в App через `useMapPreferences`. `showNavigation` по умолчанию включён и управляет видимостью кнопок масштаба и компаса MapLibre через CSS в `MapCanvas`, без пересоздания карты; меню настроек остаётся доступным. Меню маркеров отделено от слоёв. `features/map-markers/model/catalog.ts` содержит JSON-совместимые категории и два демонстрационных маркера (изначально выключены); будущий загрузчик локальных JSON должен передавать тот же контракт. Маркеры используют существующий pin и общую карточку объекта; при смене языка карточка локализуется заново.
- На десктопе инспектор — округлая карточка под поиском; на телефоне сохранены три положения sheet и прежние анимации. Видимые названия меню и моков находятся под `interface`.

## MapLibre и React

MapLibre остаётся императивным адаптером визуализации, а React хранит состояние интерфейса: активный слой, строку поиска, выбранный объект, язык и открытую карточку. Изменения React state применяются к карте через `useEffect` и методы MapLibre (`setFilter`, `setLayoutProperty`, `setPaintProperty`, `fitBounds`, `setFeatureState`). Не храните GeoJSON-копии в нескольких местах: доменный модуль источника — единственный источник его конфигурации. Raw GeoJSON не изменяется: перед передачей в MapLibre создаётся клиентская копия с `Feature.id = fid` и локализованным `properties.label`. Для `label` используется выбранная локаль, затем английская, а при отсутствии обоих названий подпись не отображается.

- Состояния переключателей слоёв по подложкам, категорий маркеров и feature flags (GeoJSON, zoom, элементы управления картой) сохраняются в `localStorage` под `map-ui-preferences-v1`. При восстановлении принимаются только известные булевы поля, новые настройки получают defaults из конфигурации; повреждённое или недоступное хранилище не блокирует интерфейс. Блок GeoJSON использует компактные строки «ключ — значение» на сером фоне.
