# Map glyphs

The `Open Sans Regular` PBF files were downloaded from
`https://fonts.openmaptiles.org/Open%20Sans%20Regular/{range}.pbf`.
They cover the Unicode ranges currently used by map labels: `0-255`,
`1024-1279`, and `8192-8447`. Open Sans is distributed under Apache
License 2.0; see `Open Sans Regular/LICENSE.txt`.

MapLibre requests 256-codepoint ranges as needed. When adding map labels
with characters outside these ranges, add the corresponding PBF file here.
